# UI 混合模式设计：运营区与内容区完整版

**日期**: 2026-08-14

## 目标

把 Amazon Control 从“统一灰色工具后台”升级为双区工作台。运营链路保留高密度、数据优先、克制专业；内容链路强调媒体预览、创作交付和视觉识别。两个区域共享设计令牌和交互语言，但页面结构、信息密度、动效力度不同。

## 总体视觉

- 底色使用浅灰绿画布 `#f2f6f4` 和极细网格线，网格大小 32px。
- 运营区使用白面板、细边线、低阴影；内容区使用深色媒体舞台与浅色编辑面板交替。
- 主操作色为信号绿 `#0e7c60`，信息蓝 `#3f6fae`，风险红 `#c14b3f`，提醒琥珀 `#d69b2e`。
- 不做紫黑渐变，不用装饰性光斑和渐变球；动效来自层级、位移、透明度和少量模糊。

## 全局壳层

### 顶部状态轨

- 左侧品牌和运行状态；中间项目名、站点、币种、语言；右侧接口状态、定时同步状态、风险提醒。
- 状态轨在滚动时固定在顶部，高度 64px，下方内容保持可读。

### 侧边导航

- 深森林绿 `#10241d` 底色，分三组：运营、内容、系统。
- 运营项紧凑，文字为主；内容项带模块色点，展开时显示 2 列媒体缩略图预览。
- 当前模块使用 3px 左侧信号条，不做大面积高亮。

### 命令面板

- 全局快捷键打开搜索面板，可搜索模块、任务、素材、接口和最近操作。
- 面板为浅色浮层，带模糊背景，键盘上下选择，回车跳转。

## 运营页模板

- 顶部页头：模块名、当前站点、数据来源、同步状态。
- 主区左侧输入面板，右侧结果面板；宽屏下可三栏：筛选、主指标、动作清单。
- 指标卡标题 12px 灰，数值 20-24px 等宽字体；趋势箭头只在有真实趋势时出现。
- 表单使用 8px 圆角、细边框，聚焦时绿色描边和轻微发光。
- 表格支持固定表头、行悬停、状态列色点；数字右对齐。

## 内容页模板

- 图片页：左侧生成参数，中间 16:10 预览舞台，右侧素材引用与生成历史。
- 视频页：顶部脚本/分镜时间线，中间 9:16 或 16:9 预览，右侧字幕、旁白、镜头清单。
- 素材库：筛选栏、媒体网格、批量选择、拖拽导入区；卡片悬停显示预览大图和引用按钮。
- 自动上架：三段路径切换、字段预览、缺失项、合规风险、导出上传表。

## 审批与执行页

- 顶部显示“人工确认模式”提示条。
- 队列卡片包含模块、方法、状态、步骤、字段预览、风险等级。
- 批准、驳回、重新加入草稿、复制操作清单为主要动作。

## 动效系统

### 页面转场

- 模块切换使用 180ms 交叉淡入淡出，方向由分组决定：运营区间左右平移，内容区间轻微上移。
- 页面首次加载按模块卡片顺序错峰出现，间隔 20ms。

### 交互反馈

- 按钮点击有 80ms 按压缩放；悬停只改变边框或阴影，不改变布局尺寸。
- 指标变化使用 160ms 数字过渡；状态点使用 200ms 颜色与透明度过渡。
- 媒体卡悬停抬升 2px，阴影加深；拖入文件时出现 2px 虚线高亮。

### 内容预览

- 图片/视频进入视口时从 96% 透明度滑入；预览舞台支持点击放大、左右切换。
- 生成中显示骨架屏和进度条；完成时预览淡入，状态徽标从琥珀变为绿色。

### 命令面板

- 打开时缩放 0.98 到 1，背景模糊 8px；搜索结果错峰出现。

## 响应式

- 桌面优先 3 栏；中屏 2 栏；窄屏 1 栏。
- 移动端侧栏折叠为底部标签，媒体网格保持 2 列。

## 验收标准

- 运营区与内容区能一眼区分，但共享同一视觉语言。
- 媒体预览、拖拽、引用、生成历史完整可操作。
- 动效存在且不阻塞高频操作。
- 状态色只用于真实状态。

## 非目标

- 不改后端数据结构和接口。
- 不引入 React、Vue 或大型组件库。
- 不做深色全局主题；先完成浅色运营区与深色媒体舞台的混合版。
